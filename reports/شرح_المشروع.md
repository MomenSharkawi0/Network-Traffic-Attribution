## 1. المشروع بيتكلم عن إيه؟

### المشكلة

في الهجمات السيبرانية الحديثة، الهاكر بيستخدم تقنيتين لإخفاء هويته الحقيقية:

1. **IP Spoofing** — بيغيّر الـ source IP في كل packet عشان مفيش حد يقدر يرجع للمصدر الحقيقي. الـ replies بتروح لـ IP غلط، والـ IDS بيشوف عنوان مزوّر.
2. **Decoy Traffic** — بيبعت آلاف الـ flows من IPs عشوائية في نفس وقت الهجمة الحقيقية. الـ flow الحقيقي بيتغرق في وسط ضوضاء عظيمة.

**المحقّق الجنائي ساعتها يقدر إزاي يميز الـ flow الحقيقي للهاكر من الـ flows المزوّرة والـ decoys؟** ده اللي المشروع بيحلّه.

### إيه اللي عملناه

بنينا **classifier** بيـ attribute كل flow: ده hat من attacker حقيقي (label=1) ولا من spoof/decoy (label=0). استخدمنا 3 موديلز:

1. **Random Forest** (200 trees, balanced)
2. **XGBoost** (300 trees, depth=6)
3. **MLP** (128-64-32 deep learning baseline)

النتيجة: **دقّة 100%** على الـ synthetic sample بتاعنا.

## 2. عملنا إيه بالظبط

### الـ Pipeline

```
الـ raw data
    ↓
[preprocess.py]   ← تحميل وتنظيف
    ↓
[features.py]     ← 14 attribution feature
    ↓
[train.py]        ← تدريب RF + XGB (5-fold CV)
    ↓
[evaluate.py]     ← قياس الأداء + plots
[predict.py]      ← استخدام الموديل المُدرَّب
```

### الـ Dataset

استخدمنا **synthetic dataset** بنحاكي فيه:
- **Real attacker flows:** TTL ثابت (64 أو 128 أو 255)، TCP window ثابت، source IP entropy واطية، retransmission واطي.
- **Spoof / Decoy flows:** TTL عشوائي، entropy عالية في الـ IPs، TCP window متغيّر، retransmission عالي.

10 آلاف صف total، 50/50 متوازن، seed=42.

والـ pipeline بيشتغل برضه على **CIC-DDoS2019** (الـ dataset الحقيقي من University of New Brunswick) لو حمّلته في `data/raw/`.

### الـ 14 Features

1. `ttl_mean` — متوسّط الـ TTL
2. `ttl_variance` — تباين الـ TTL (الـ spoof بيكون عالي)
3. `src_ip_entropy` — Shannon entropy للـ source IP
4. `tcp_window_size_mean` — متوسّط الـ TCP window
5. `tcp_window_size_std` — انحراف الـ TCP window
6. `tcp_options_hash` — fingerprint للـ OS
7. `packet_size_mean` — متوسّط حجم الـ packet
8. `packet_size_std` — انحراف الـ packet size
9. `interarrival_mean` — متوسّط الوقت بين الحزم
10. `interarrival_variance` — تباين التوقيت
11. `flow_duration` — مدة الـ flow
12. `packets_per_second` — معدل الحزم
13. `bytes_per_packet` — متوسّط البايتس
14. `retransmission_ratio` — نسبة retransmission

### الموديلات

**Random Forest:** 200 شجرة، `class_weight="balanced"`, seed=42.

**XGBoost:** 300 شجرة، depth=6، lr=0.1، `tree_method="hist"`.

**MLP (sklearn):** `hidden_layer_sizes=(128, 64, 32)`, ReLU, Adam, max_iter=200, batch_size=256, StandardScaler على الـ features.

### الـ Training Protocol

1. Split 80/20 stratified (random_state=42).
2. 5-fold CV على الـ training set.
3. تدريب على كامل الـ training split.
4. تقييم على الـ held-out test split.

| MLP | 1.0000 | 1.0000 | 1.0000 | 1.0000 | 1.0000 |

### Top 5 Features (RF importance)

1. `ttl_variance` (~20%)
2. `src_ip_entropy` (~16%)
3. `tcp_window_size_std` (~12%)
4. `retransmission_ratio` (~10%)
5. `interarrival_variance` (~9%)

**Insight:** تلاتة من أهم خمس features هما **variance / stddev** statistics. ده مهم — يعني الـ "stability" هي الـ signal الأقوى للـ attribution. الـ real attacker مستقر. الـ spoof/decoy فوضوي.

## 4. لو الدكتور سأل: "ليه الـ 1.000؟"

- **ج:** ده على الـ synthetic sample اللي مولّدناه. الـ classes فيه متفرّقة جدًا لأن الـ generator بيحاكي two clear distributions. الـ Sharafaldin et al. (2019) على الـ real CIC-DDoS2019 وصلوا لـ 0.998 — يعني الـ task فعلاً separable بقوة لما الـ features محسوبة صح. لو شغّلنا الموديل على captures حقيقية متوقّعين نلاقي الرقم من 0.97 لـ 0.998.

## 5. لو الدكتور سأل: "إيه عيوب الموديل؟"

1. مش بياخد cross-flow features (route diversity, RTT consistency من multiple flows).
2. متدرّب على synthetic data — production numbers هتبقى أقل.
3. attacker carefully shapes الـ spoof عشان يبان زي real source ممكن يكسر الموديل.
4. مش بياخد temporal patterns على نطاق طويل.

## 6. الخلاصة في جملة

> "بنيت ML pipeline يعمل attribution للـ network flows ويفرّق بين الـ real attacker والـ spoof/decoy عن طريق 14 statistical feature. استخدمت Random Forest و XGBoost و MLP، ووصلت دقّة 100% على الـ synthetic sample، مع feature importance بيوضّح إن الـ TTL variance والـ source-IP entropy هما أهم signals."
